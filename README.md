# Dingo

Учебный метапоиск отелей. Загружены реальные каталоги Островка и 101Hotels для девяти городов: Москва, Санкт-Петербург, Казань, Сочи, Ялта, Калининград, Краснодар, Волгоград и Ростов-на-Дону.

## Запуск

Нужен Node.js 22.12+. Из папки проекта:

    npm ci
    npm start

Открыть [Dingo на порту 3010](http://127.0.0.1:3010). Порт 3000 может использовать другой сервис. Настройки — в .env.example.

При открытии через Live Server на другом локальном порту frontend автоматически проверяет backend Dingo на 3010. Если backend выключен, отображается сохранённая подборка, а у номеров — понятное сообщение и ссылка на источник. HTML-страница ошибки не разбирается как JSON.

## Исправления интерфейса

- Левая панель ограничена высотой окна и прокручивается независимо: «Источник» и «Тип размещения» доступны даже при небольшой высоте экрана или увеличенном масштабе. На мобильном экране фильтры прокручиваются со страницей. Палитра, шрифты и общий дизайн сохранены.
- Добавлен выбор источников и три новых города. Все фильтры работают совместно.
- Номера Островка читаются из hotel.roomGroups, номера 101Hotels — из карточек .room-name-cell[data-room-id].
- Кнопка бронирования ведёт на конкретный объект. Для Островка и 101Hotels передаются параметры дат и числа взрослых; у Суточно.ру сохраняется каноническая ссылка.
- Одинаково названные номера разных объектов не объединяются, фото берётся только из соответствующей карточки.

## Цены

Публичный каталог Островка публикует datelessRate без выбранных дат. У 101Hotels priceRange содержит среднюю цену; сумма на странице с датами может быть предварительной стоимостью всего проживания. Эти значения не подтверждают тариф для конкретных дат, гостей, питания и отмены.

Карточка теперь пишет «Уточнить цену». Данные разделены:

- price: null — тариф на выбранные даты не получен;
- referencePrice — справочная цена каталога за ночь;
- priceMode: "source-only", availabilityChecked: false.

Фильтр «Цена в каталоге за ночь» и сортировка «дешевле/дороже по каталогу» используют referencePrice. Это ориентир для подбора, а не цена бронирования.

Для точных тарифов нужен доступный поставщик динамических цен. У Островка есть [Affiliate API ETG](https://docs.emergingtravel.com/docs/affiliate-api/hotel-search/search-by-hotel-ids/), требующий партнёрского доступа. В этой версии API-ключей и подключения к нему нет. Совпадение окончательной цены на выбранные даты пока не обеспечивается.

## Обновление каталога

Подставьте будущие даты; CLI проверяет их, но выгружает справочный каталог:

    npm run scrape -- 2027-01-10 2027-01-13 2 "Москва" "Санкт-Петербург" "Казань" "Сочи" "Ялта" "Калининград" "Краснодар" "Волгоград" "Ростов-на-Дону"

При поиске город обновляется, если последняя попытка была более 30 минут назад. Пустой город показывает всю сохранённую подборку. Ошибки тоже кэшируются на 30 минут, чтобы не отправлять запросы при каждом нажатии.

hotels.json содержит version: 2, hotels, statuses, updatedAt. У записи есть источник, канонический URL, страница каталога и время получения. Запись атомарная; сбой источника сохраняет его прошлую успешную выгрузку. Старые priceKind: "reference" автоматически переводятся в referencePrice.

Ненулевой код CLI означает, что хотя бы один источник не обновился; успешные данные сохранены. После ручного обновления файла перезапустите уже работающий сервер.

## Источники

16 ноября 2026 года проверены каталоги Островка и 101Hotels во всех девяти городах. Сохранено 364 объекта: 180 с Островка и 184 с 101Hotels.

Суточно.ру с машины проверки не отвечает: соединение завершается тайм-аутом. Его карточек в выгрузке нет, показывается статус недоступности. Тесты Суточно.ру используют синтетический HTML; Островок и 101Hotels дополнительно проверены на фрагментах реальных ответов.

Можно импортировать локально сохранённый HTML:

    npm run scrape -- --import sutochno "Москва" "C:\путь\к\saved.html"

Поддерживаются также ostrovok и hotels101. Время сохранения исходной страницы неизвестно: fetchedAt: null, отдельно сохраняется importedAt. Импорт без распознанных карточек не очищает каталог.

## Проверки и API

    npm test

Тестируются реальные карточки и номера двух источников, отдельное хранение справочных цен, новые города, фото и идентификаторы, фильтры, ссылки, HTML вместо JSON, подключение статического предпросмотра к backend, кэш при сбое и HTTP API.

- GET /api/health — идентификатор сервиса Dingo.
- GET /api/hotels?city=Краснодар&checkin=2027-01-10&checkout=2027-01-13&adults=2 — каталог с обновлением выбранного города.
- GET /api/rooms?id=… — категории номеров известного объекта, кэш на 30 минут.

Произвольные внешние URL не принимаются. .env, .git и серверные исходники не раздаются посетителю.
